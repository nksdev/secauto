# Security Policy

SecAuto is a security assessment and reconnaissance tool. Use it only against
systems you own or have explicit permission to assess.

## Reporting a vulnerability

Do not publish exploit details, credentials, personal data, or other sensitive
evidence in a public issue. Use GitHub's private vulnerability reporting feature
for this repository when available, or contact the maintainer through a
verified private channel.

## Safe operation

- Confirm written authorization and scope before scanning.
- Start with passive checks and conservative concurrency.
- Avoid scanning production systems without a documented test window.
- Review generated reports before sharing; they may contain sensitive target
  and infrastructure information.
