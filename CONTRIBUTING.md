# Contributing to SecAuto

Thanks for considering a contribution.

1. Open an issue to discuss significant changes before implementation.
2. Keep scanners modular and preserve the authorization gate.
3. Do not add destructive checks, stealth/persistence behavior, or hard-coded
   credentials.
4. Add or update tests for behavior changes.
5. Run the test suite with `python -m unittest discover -s tests -v` before
   opening a pull request.

By contributing, you confirm that you have the right to submit the changes
under the project's MIT license.
